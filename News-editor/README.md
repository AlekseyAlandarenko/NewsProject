# News Editor

Frontend-приложение для создания и редактирования новостных статей с поддержкой форматирования текста, загрузки файлов и real-time уведомлений.
Проект реализован в рамках **демонстрационного frontend-проекта**.

## Основной функционал

### Редактор статей
- Добавление текста с форматированием (жирный, заголовки, списки)
- Добавление изображений
- Добавление цитат
- Добавление блоков кода (Markdown)
- Добавление файлов (PDF, DOC и др.)
- Перемещение и удаление блоков
- Предпросмотр статьи

### Real-time уведомления
| Событие           | Описание                              |
|-------------------|---------------------------------------|
| `article:added`   | Добавление новой статьи               |
| `article:updated` | Обновление существующей статьи        |

> **Примечание:** Уведомления реализованы через Firestore (onSnapshot) и отображаются в интерфейсе в виде «колокольчика».

## Архитектура
Проект построен на **компонентной архитектуре (React)**
- **Components** — UI-компоненты и логика отображения
- **Hooks** — кастомные React-хуки
- **Context** — глобальные состояния (Toast-уведомления)
- **Interfaces** — типы данных
- **Utils** — вспомогательные функции
- **Styles** — SCSS-стили
- **Firebase** — Firestore, Storage и Auth

### Дополнительно реализованы

- Блочный редактор статей
- Предпросмотр с рендерингом HTML и Markdown
- Подсветка кода
- Загрузка файлов в Firebase Storage
- Real-time уведомления
- Централизованные Toast-уведомления
- Очистка HTML через DOMPurify

## Технологии

## Быстрый старт

### 1. Клонирование
```bash
git clone https://github.com/AlekseyAlandarenko/NewsProject.git
cd NewsProject/News-editor
```

### 2. Установка зависимостей 
```bash
npm install
```
### 3. Установка Firebase CLI
```bash
npm install -g firebase-tools
```

### 4. Авторизация в Firebase
```bash
firebase login
```

### 5. Запуск Firebase Emulators
```bash
firebase emulators:start
```
Будут запущены:
| Сервис            | Порт                                  |
|-------------------|---------------------------------------|
| **Firestore**     | 8080                                  |
| **Storage**       | 9199                                  |
| **Auth**          | 9099                                  |
| **Emulator UI**   | 4000                                  |

Панель эмуляторов:
```md
http://localhost:4000
```
### 6. Запуск приложения
В отдельном терминале:
```bash
npm run dev
```
Приложение будет доступно по адресу:
```md
http://localhost:5173
```
> **Примечание:** При запуске на localhost приложение автоматически подключается к Firebase Emulators.

### Типы блоков статей
- Текст
- Изображение
- Цитата
- Код (Markdown)
- Файл

### Форматирование текста
Поддерживаются:
- Жирный текст
- Заголовки
- Маркированные и нумерованные списки
- Ссылки

### Предпросмотр
Предпросмотр статьи отображает:
- Отформатированный текст
- Изображения
- Цитаты
- Подсвеченный код
- Ссылки на файлы

### Уведомления
Компонент **NotificationBell** отображает:
- Добавление статей
- Обновление статей
Все события приходят в реальном времени через Firestore.
